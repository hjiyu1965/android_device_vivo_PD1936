# Plan: Binder GuardianAngle 调用方案

## 背景

从分析已知：
- `guardianangle` 守护进程已注册为 binder 服务 "GuardianAngleService"
- `BpGuardianAngleService::verifyUserPassWord(int, String16)` — transact code=1
- `libGuardianAngleClient.so` 导出 `GetGuardianAngleService()` → 返回 `sp<IGuardianAngleService>`
- `libGuardianAngleServiceImpl.so` 的 `GuardianAngleService::verifyUserPassWord` 会调用 `VivoGuardManager::verifyPassword` + fscrypt_unlock

## 方案：直接链接 libGuardianAngleClient.so

```cpp
// gadecrypt.cpp
#include <binder/IServiceManager.h>
#include <binder/Parcel.h>
#include <utils/String16.h>

// 声明 libGuardianAngleClient.so 的导出函数
extern android::sp<android::IBinder> GetGuardianAngleService();

int main(int argc, char* argv[]) {
    int userId = atoi(argv[1]);
    const char* password = argv[2];

    // 获取 GuardianAngle Binder 代理
    sp<IBinder> binder = GetGuardianAngleService();
    if (!binder) return 1;

    // 构造 Binder 调用: transact(1) = verifyUserPassWord
    Parcel data, reply;
    data.writeInterfaceToken(String16("android.IGuardianAngleService"));
    data.writeInt32(userId);
    data.writeString16(String16(password));

    status_t status = binder->transact(1, data, &reply);
    if (status != NO_ERROR) return 1;

    return reply.readBool() ? 0 : 1;
}
```

## 构建方式

两种选择：

### A. 本地 NDK 编译（推荐）
用 TWRP 源码中的 clang++ 交叉编译，链接到设备树里的 .so 文件：
- `libbinder.so` + `libutils.so` (Android framework)
- `libGuardianAngleClient.so` (vivo 专用，设备树已提供)
- `libc++.so`

### B. CI 中编译
在 CI workflow 的 Build recovery 步骤中，先编译 gadecrypt 再编译 recovery：
```
cp gadecrypt.cpp bootable/recovery/crypto/fscrypt/
sed 追加到 Android.mk（已解决，用 EXECUTABLES + RECOVERY_EXECUTABLES + LOCAL_MULTILIB）
```

## 关键修正

之前 CI 失败是因为 `RECOVERY_EXECUTABLES` + `LOCAL_MODULE_PATH` 触发 multiarch 检查。修复方案：
```makefile
LOCAL_MODULE := gadecrypt
LOCAL_MODULE_CLASS := EXECUTABLES
LOCAL_MODULE_RELATIVE_PATH := system/bin
LOCAL_MULTILIB := first   # 关键：避免 multiarch 冲突
LOCAL_SRC_FILES := gadecrypt.cpp
LOCAL_SHARED_LIBRARIES := libbinder libutils libc++
LOCAL_LDFLAGS += -L$(TARGET_RECOVERY_ROOT_OUT)/system/lib64 -lGuardianAngleClient
include $(BUILD_EXECUTABLE)
```

## 集成到 TWRP

CI workflow 中修改 `patch_decrypt.py`：在 `Decrypt_User()` 里，spblob 检查失败后，调 `system("gadecrypt 0 'password'")`。

## 验证步骤

1. CI 编译成功 → 下载 recovery.img
2. `adb shell gadecrypt 0 '123456'` → 返回 0 表示验证通过
3. `adb shell ls /data/media/0/` → CE 文件名可读（不再是加密名）
